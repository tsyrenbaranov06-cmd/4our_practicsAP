# Соединение строк двух матриц

Функция `concat_rows` создаёт массив строк разной длины, соединяя соответствующие строки двух матриц. Оставшиеся строки более высокой матрицы копируются отдельно.

## Ввод

Сначала четыре положительных целых числа: `n1 m1 n2 m2`. Затем элементы первой матрицы построчно, после них — второй.

```text
3 2 2 3
1 2
3 4
5 6
7 8 9
0 1 2
```

Результат:

```text
1 2 7 8 9
3 4 0 1 2
5 6
```

Коды завершения: `0` — успех, `1` — ошибка ввода, `2` — ошибка выделения памяти. Пустые матрицы считаются ошибкой ввода.

## Сборка

Через g++:

```sh
g++ -std=c++14 -Wall -Wextra main.cpp -o concat_rows
```

В Developer Command Prompt for Visual Studio:

```bat
cl /nologo /EHsc /W4 /std:c++14 main.cpp /Fe:concat_rows.exe
```

## Проверки и объяснение

В `checks.txt` сохранены результаты восьми проверок ввода и работы программы, а также проверки отказа каждого из 11 выделений памяти на отдельной инструментированной копии. Проверочный механизм не включён в основной исходный файл.

В `EXPLANATION.md` находится разбор функций, указателей, выделения памяти и примера.
