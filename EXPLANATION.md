# Как работает программа

Программа соединяет строки двух матриц. Например, строка `1 2` из первой и строка `7 8 9` из второй превращаются в `1 2 7 8 9`. Если в одной матрице строк больше, оставшиеся строки просто копируются в результат.

## Как хранится матрица

`int **matrix` — указатель на массив указателей. Каждый `matrix[i]` указывает на отдельный массив целых чисел — строку. `matrix[i][j]` означает элемент в строке i и столбце j. Индексы начинаются с нуля.

Строки выделяются отдельно, поэтому могут иметь разную длину. Это нужно для результата: строки, общие для двух матриц, имеют длину m1 + m2; оставшиеся строки имеют длину m1 или m2.

`n1` и `m1` — число строк и столбцов первой матрицы. `n2` и `m2` — второй. `lhs` — первая матрица, `rhs` — вторая, `result` — результат.

## Подключённые библиотеки и основные обозначения

- `<iostream>` даёт `std::cin`, `std::cout` и `std::cerr`: ввод, вывод и сообщения об ошибках.
- `<new>` нужен для `std::bad_alloc` — исключения при нехватке памяти.
- `<cstddef>` определяет `std::size_t`, беззнаковый целочисленный тип для размеров и индексов.
- `<limits>` позволяет узнать максимальное значение типа через `std::numeric_limits<size_t>::max()`.
- `using std::size_t;` позволяет дальше писать `size_t` без приставки `std::`.
- `nullptr` означает, что указатель ни на что не указывает.
- `sizeof(int)` — сколько байтов занимает одно целое число; `sizeof(int *)` — сколько занимает указатель.
- `static_cast<size_t>(n1)` явно преобразует число к типу размера.

## delete_matrix — освобождение памяти

Сначала проверяется, существует ли матрица. Затем цикл освобождает каждую строку через `delete[] matrix[i]`. После этого `delete[] matrix` освобождает сам массив указателей.

Порядок важен: если сначала удалить массив указателей, адреса строк будут потеряны.

## create_matrix — выделение памяти

Функция получает число строк n и столбцов m. Проверка через `limit / sizeof(...)` предотвращает переполнение размера выделяемой памяти.

`new int *[n]` создаёт массив из n указателей. Затем `new int[m]` создаёт каждую строку из m чисел.

`created` считает успешно созданные строки. Если `new` выбросит `std::bad_alloc`, блок `catch` освободит уже созданные строки и вернёт `nullptr`. Этот счётчик нужен, чтобы не пытаться удалить строки, которые ещё не созданы.

## read_matrix — ввод элементов

Внешний цикл перебирает строки, внутренний — столбцы. Каждый элемент читается командой `std::cin >> matrix[i][j]`.

Если ввод не удался, возвращается `false`. Если все элементы прочитаны — `true`. Память освобождает вызывающая функция main.

## concat_rows — основная функция задания

`const int *const *lhs` и аналогичный параметр rhs запрещают менять элементы исходных матриц и указатели на их строки через эти параметры. Результат создаётся в новой памяти.

Количество строк результата — большее из n1 и n2:

```cpp
size_t n = n1 > n2 ? n1 : n2;
```

Запись `условие ? значение1 : значение2` означает: если условие верно, взять значение1, иначе значение2.

Для каждой строки определяются две длины:

```cpp
size_t left = i < n1 ? m1 : 0;
size_t right = i < n2 ? m2 : 0;
```

Если строка i есть в первой матрице, left равен m1, иначе нулю. Аналогично right для второй матрицы.

Затем создаётся строка длиной left + right. Первый цикл копирует элементы первой матрицы в начало строки:

```cpp
result[i][j] = lhs[i][j];
```

Второй цикл дописывает элементы второй матрицы:

```cpp
result[i][left + j] = rhs[i][j];
```

Смещение left нужно, чтобы начать запись после элементов первой матрицы. Если left или right равен нулю, соответствующий цикл не выполняется. Обращения к несуществующей строке при этом не происходит.

Проверка `m1 > limit - m2` проверяет возможность сложения размеров без переполнения. При нехватке памяти освобождаются уже созданные строки результата и возвращается `nullptr`.

## main — порядок действий

1. Читает четыре размера и проверяет, что они положительные.
2. Создаёт обе исходные матрицы.
3. Читает их элементы.
4. Вызывает concat_rows.
5. Выводит каждую строку результата с её собственной длиной.
6. Освобождает обе исходные матрицы и результат.

Если на любом этапе происходит ошибка, перед выходом освобождается уже выделенная память.

Коды завершения программы:

- `return 0` — успешно.
- `return 1` — неверный ввод.
- `return 2` — ошибка выделения памяти.

## Пример со скриншота

Ввод:

```text
3 2 2 3
1 2
3 4
5 6
7 8 9
0 1 2
```

Результат:

```text
1 2 7 8 9
3 4 0 1 2
5 6
```

У первой матрицы три строки, у второй две. Первые две строки соединяются попарно, третья строка первой матрицы копируется отдельно.

## Что стоит уметь объяснить самому

Почему используется int **: результат содержит отдельно выделенные строки разной длины.

Почему нельзя всегда выделять и выводить n строк по m1 + m2 элементов: у оставшихся строк более высокой матрицы длина меньше, и лишние элементы не являются частью результата.

Зачем нужен created: при ошибке выделения нужно удалить только успешно созданные строки.

Почему исходные матрицы не меняются: concat_rows только читает их элементы и копирует в новую память.
